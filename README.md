# Simba Coach Bus Booking

A responsive, static bus-booking site with route selection from all 47 Kenyan county headquarters, estimated fares, four sample bus options and four sample matatu options for each route, seat selection, passenger details, and a WhatsApp booking-request handoff.

## Run locally

Open `index.html` in a browser. The sample search route can be loaded with:

`index.html?from=Nairobi&to=Mombasa&date=2026-10-22&pax=1`

## Publish with GitHub Pages

In the repository, open **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and `/ (root)`, then save. GitHub Pages will publish the static site.

Fares, departure times, and seat counts are sample estimates and must be confirmed with the operator. Booking requests are prepared for WhatsApp number `+254105686866`; a passenger must review and send the message in WhatsApp. No payment is processed by this static page.
